## 已确认边界

- A/B/C继续使用原始数据，不用复验耗时覆盖原始耗时。
- 原始940次运行由480次规模、180次通道和280次故障工况组成；A与B共享任务，不额外增加样本。
- 身份复验：safe success 245 -> 245，invalid replay 9 -> 0，protective pause 13 -> 22，unreachable 13 -> 13。九个错误转为保护暂停，不计为成功率提升。
- 245个共同成功工况的路径长度及makespan保持一致。
- 连续量误差棒为样本SD；成功率误差棒为Wilson 95%区间。有效makespan按通过审计的样本计算，保留各项metric_n，尤其A的Uncoordinated A*有效makespan仅n=2/20。
- 非负指标坐标从0开始，低于0的误差部分仅在显示时裁切；带符号的Makespan change保留负值显示范围。
- 这是软件仿真与复验结果，不是实物液滴闭环结果。
