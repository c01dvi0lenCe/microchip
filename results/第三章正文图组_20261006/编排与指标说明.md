## 指标口径

- `N_d`：任务液滴数，不是单幅快照中已释放滴数。
- `L_total`：各静态路径的图边数之和，即每滴`len(path)-1`；不是毫米距离，不包括None延迟或Wait。
- `T_makespan`：最长scheduled_path的长度减1，计离散调度步，不是实际硬件运输秒数。
- `N_wait`：各原始scheduled_path中两个相邻非None位置相同的次数之和。只统计原始序列，不计绘图阶段为已完成滴补出的末端保持。
- `t_release`：scheduled_path中第一个非None位置的下标。释放延迟与Wait分别记录。
- `R_detour`：比较路径长度总和除以原路径长度总和。静态案例比较全程，运行时案例仅比较故障时刻的剩余路程，分母不可混用。
- `T_replan`：重规划计算的主机实测耗时，单位ms；不能与离散调度步混用。当前导出是单次计时，不写成重复实验平均性能。

### C_static=66的准确含义

复杂任务使用独立审计器`audit_schedule`逐时刻检查每一个无序液滴对。每个“液滴对-时间步”最多计一次违规，分类优先级为vertex、edge_swap、spacing、transition_spacing。对已完成滴继续保持其目标位置，对尚未释放滴不计占据。

| 分类 | 独立A*固定间隔释放 | 现有协调 |
| --- | ---: | ---: |
| vertex | 28 | 0 |
| edge_swap | 0 | 0 |
| spacing | 13 | 0 |
| transition_spacing | 25 | 0 |
| 合计 | 66 | 0 |

66不是66个独立液滴对、不是66个不同时间步，也不是实物观测到的66次碰撞；其中50个为跨来源液滴对的违规计数。

三个对照共享同一源目标分配与静态障碍。独立A*参考对每个储液池使用固定3步出滴间隔，无跨来源协调；安全串行参考一次执行一项运输并保护已经占据的目标；现有并行方案直接读取生产算法输出，未在导出脚本中修改调度。

| 方案 | L_total | T_makespan | N_wait | 冲突对-时间步数 | 是否通过安全审计 |
| --- | ---: | ---: | ---: | ---: | --- |
| 独立A*固定间隔释放 | 183 | 27 | 0 | 66 | 否 |
| 安全串行参考 | 183 | 183 | 0 | 0 | 是 |
| 现有并行协调 | 183 | 34 | 36 | 0 | 是 |

不安全参考的27步不能称作有效运输完成时间。本案例中，34步相对安全串行的183步减少81.4%，只支持该任务和明确参考方案下的效率结论，不是全局最优或普遍算法优势证明。

| 案例 | 已核对结果 |

全部结果是软件仿真，不是实际高压、真实液滴或实物闭环完成证据。正文图注可统一注明仿真条件，无需每幅图增加说明框。
