# 视频约束的仿真速度核查

用户批准先从现有视频估计一格迁移时长，再约束模拟速度。只新增离线量测材料；不改4.8 mm/s既有trial、不重跑、不改变正式结果。采用原始视频及其现有接收时间sidecar；接收时间不称曝光时间，容器时间与接收时间分别报告。

固定核查有sidecar的20261014_112318视频630–810帧及已审核ROI(1566,2760,570,336)，复用Otsu基线，不重新训练。新Mask为自动量测草稿，不是人工GT。先保存全部逐帧质心及缺失，再从可见往返迁移中说明量测区间。使用既有局部网格周期118×119 px和设计pitch3.2 mm仅作近似标尺；不绑定旧照片H，不推断真实190/191身份。

输出时间源审计、逐帧草稿、可追溯预览、区间时长/位移及速度假设建议。没有足够时空证据时不输出正式校准参数，不直接改运动模型。
