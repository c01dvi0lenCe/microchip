# 实验一最新范围：真实电极几何单液滴到达识别（r2）

本规格记录用户在实施中追加的最新约束，取代此前单步规格中的位置噪声.03mm/s和突然匀速停止设置。尚无持久化研究trial；临时单元测试夹具不计研究结果。保留旧文档作过程记录，不覆盖冻结研究成果。

- 标题：基于真实电极几何的单液滴到达状态识别仿真。
- 首先计算真实190/191、4mm等效紧凑模板在0/25/50/75/100%位置的静态交叠。静态图沿用紧凑轮廓，另列动态形变，不能冒称实际时间帧。居中终点若候选rho≥.90/eta_source≤.08不可达，则停止运行并报告，不改运动迎合阈值。
- 研究trial保持normal/264900、3s、.5请求、.54模拟Applied、.18响应延迟、dt.01、20fps。噪声严格0，无丢帧、边缘错误或处理抖动。
- 平滑运动使用最小跃度q=10u³−15u⁴+6u⁵，u为累计有效运动时间/T；T=1.875×源目标距离/4.8，使峰值速度≤4.8mm/s。无交叠时运动时钟暂停；相同目标重发不重置。此为现象学平滑运动曲线，不是真实动力学识别。
- 保持面积的形变同前（沿轴λ、横向1/λ，λ目标1+.55sinπq，时间常数.1s）。高度.8mm仅记录。
- 同一持久化Mask供三方法：M1=C0+G；M2=C0+G+Q+W；M3=C0+G+Q+W+S+K。G=rho_target≥.90、eta_source≤.08候选；W≥5帧且跨度≥.25s（20fps连续规则通常6帧）；S=质心目标距离≤.576mm；K=C0可解析原始历史速度≤19.2mm/s，>.18s断档清历史，不要求单调前进；Q保留已声明可观测面积/连通域有效性，正常缓存三者相同。不得将M3称完整五状态控制器。
- Q/W/S/K所有原始输入逐帧保存，K不按判据开关过滤历史；三个到达门只观察，不发任何控制。C0与共同基本有效性不关闭。旧eta_target.85门只诊断，不进入新候选G。
- 独立内部位置/速度/驻留参考保持.288mm/.192mm/s/.15s，评分不读预测。不保证M3优于M2；一致和提前/晚确认均报告。

- 单例只输出确认时刻、偏差和是否支持/未确认，不输出准确率或多次统计。异常与消融、多seed为后续方案，不执行。
