# S1两张核心科研图设计

依据用户本轮明确批准的两图要求实施，不另行调整研究内容。

## 图稿契约

- S1-A解释同一次190→191迁移中，内部位置、模拟观测与状态/事件的区别。2×3主面板保留0.50/0.81/1.06/1.46/1.92/1.96 s；顶部小路线图按真实地图多边形展示190→191→192→172并强调首段。主面板源190/目标191配色固定，world.active另用绿色轮廓。1.96 s另说明当前任务已为191→192，拒绝旧Mask，内部位置仍显示。
- S1-B解释同trial空间观测随任务迁移的变化。三个对齐面板依次为内部/观测x/y、eta_source/eta_target、记录的目标距离/方向进展。保留全部记录，不重新提取特征；缺失/epoch/任务切换打断连接。任务阶段由日志Start/Update的模拟Applied划分：0.54、1.96、3.05 s，结束4.11 s；0–0.54 s为源准备。阶段不宣称world.active同tick已改变。
- 两图分别为图像/示例复合图、定量时间序列图。只支持n=1机制说明，没有总体性能或CI。
- 183 mm宽，白底，统一蓝/橙/绿角色编码；最小字形≥5 pt，SVG/PDF文字可编辑，PNG600dpi。全部标SIMULATION、pitch、n=1机制示例和非真实U-Net。
- 公共架构和原第3/5页不进入本轮两图。历史源图不覆盖。

## 边界

同一trial normal:262000:F:end_to_end:full。只读PersistedReplay和已有绘图样式，不调用模型/相机/识别器或重评分。新增独立脚本与测试，生产源码不改。所有补充特征必须来自原frames.csv。无Stationary/Deviation/Retry/Recovery补造。图源、完整原始CSV/Mask引用、参数/地图/manifest和来源hash保留。

## 验收

新测试先失败后实现：固定时刻与状态；路线真实几何；1.96旧Mask拒绝；任务阶段来自事件；距离/进展与原CSV逐项一致；缺失与跨epoch断线；脚本无模拟运行入口。两图最终布局对齐、文本、碰撞与逐面板视觉检查通过，既有过程图回归不退化。无需大规模仿真或算法全量复测，不Commit/Push。
