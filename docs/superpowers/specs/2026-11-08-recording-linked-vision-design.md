# 录像联动视觉检测

用户确认：开始录像自动准备检测，停止录像同时保存检测记录；检测异常保留原视频，任何联动不操作电极。

- 默认开启“录像联动检测”，可取消后使用原独立录像/检测。
- 点击录像先启动或复用检测器，最多等待30秒模型准备；失败/超时明确告警后仍录像。实际录像开始由相机命令返回确认，不将按钮时间当曝光时间。
- 每段录像建立同名 `.vision-session.json`，链接原录像已有时间/电极侧车和检测目录，记录单调时钟的请求/返回/停止边界及错误。检测已有的录像前结果不冒称录像内结果。
- 停止录像封闭新检测输入，完成已开始的完整区域/图像后刷盘，不写半张Mask。录像和检测保存均完成后才允许下次联动。独立检测已在运行时复用，但停止本段联动录像也停止该检测，边界写入索引。
- 关闭相机、录像启动/停止失败、检测手动停止均保留不完整原因；不会改变手动/定时开环任务，不接入M3。
- 双层模式保存实际处理区域Mask；完整同帧模式联动时也保存已完成Mask。无叠加视频自动编码，避免额外实时负担。
- 软件用虚拟相机命令和预测器验证，不连接真实相机/串口。不训练、不改GT、正式仿真或STM32。
