# 真实实验上位机与独立仿真入口分离（已按用户明确分工批准）

- 日常main.py只启动真实实验操控界面：固定实物语义、默认串口断开，不自动开启串口/相机/电极；没有仿真模式切换、虚拟液滴、模拟相机或仿真循环。
- “手动电极”承载直接电极开关、普通路径定时开环及多组四宫格同步开环。任务选点与电极开关采用显式工具切换，选点不发电极指令。保留16格提醒和自动拒绝规则。
- “自动化路径规划”留给视觉反馈任务；本轮显示实际未就绪条件，启动禁用，不把旧模拟闭环接到实物。真实视觉接口继续在独立研究流程准备，不虚构已通过配准/到达验收。
- 独立run_planning_simulator.py由研究工作流使用，保留既有仿真能力。冻结S1/S2/S3、研究源码和结果目录不移动、不重跑。
- 两入口复用同一dmf.layout及CanvasController几何/编号/外围连接定义，不复制另一套理想网格。不改第三章调度、STM32、300Hz或串口事务协议。
- 多组未完成任务应逐组报告起点、终点、四点数量缺项，并定位首个未完成组。不能自动猜测或补充任务点；未完成时不提交事务。
- 独立profile隔离日常UI与兼容研究测试；既有构造器兼容保留，main明确选择operator_only=True。operator_only不初始化仿真对象，后端误调模拟入口亦拒绝。
- 仅软件验证/内存串口，不连接或输出实际AM，不Commit/Push。

实施验收：界面/入口隔离、手动页开环与自动页视觉未就绪、缺项定位、共享420几何均已实现；独立规格及质量复核通过。最终1289项回归（1可选跳过）、编译、7软件链及内存串口通过，不构成实物视觉闭环验收。新操作说明见docs/operator-only-ui-2026-11-07.md。
