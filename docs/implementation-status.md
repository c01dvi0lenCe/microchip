# 实现状态

本文用于区分“已通过软件测试的能力”和“仍需固件或实物验证的能力”。

| 范围 | 状态 | 当前证据与限制 |
| --- | --- | --- |
| 20 x 20 核心阵列及外围电极编号 | 已实现 | 软件使用 ID 1-420，并包含四角废液池和侧边储液池拓扑测试。 |
| A* 单液滴路径规划 | 已实现 | 包含直线、绕障和无路径测试。 |
| 多液滴动态调度 | 已实现于仿真 | 检查同格、对撞、正交/对角拉拽风险及停靠液滴阻塞；尚未用真实液滴时序验证。 |
| 移动、循环、混合、分裂 | 已实现于仿真 | 动作、电极保持、失败重试和视觉确认均为软件模型。 |
| 仿真相机与质心检测 | 已实现 | 可生成噪声、丢帧和低对比画面，并把检测映射到仿真电极。 |
| 离线视频液滴跟踪 | 已实现 | 支持 ROI、质心/前沿、速度和透视阵列映射；当前视频不是 20 x 20 实物阵列。 |
| STM32 电极命令生成 | 部分实现 | 上位机生成 `SET:<id>:<0|1>` 并可通过 115200 波特率串口发送。 |
| STM32F407 接收与解析固件 | 未包含 | 本仓库没有 `.c`、`.h` 或 `.ioc` 固件，无法证明 MCU 已解析和执行命令。 |
| 行列扫描与高压板时序 | 未实现 | 扫描寄存器、锁存、消隐、双极性脉冲和高压开关时序需在固件及电路上确定。 |
| 实时工业相机采集 | 占位 | 实物模式目前通过串口发送 `CAMERA:*` 占位命令并显示占位图，不是工业相机 SDK/USB3 实时采集。 |
| 真实阵列四角标定 | 算法存在，尚未接入主界面 | `ArrayGridCalibration` 支持透视映射，但尚未形成相机标定、保存和实时应用流程。 |
| 实物视觉闭环 | 未验证 | 必须完成相机采集、阵列标定、STM32 固件和高压硬件后才能验证。 |
| 硬件打样后的安全与可靠性 | 未验证 | 包括耐压、爬电距离、接插件、液滴响应时间、疏水层一致性和污染实验。 |

## 当前可以用于论文的数据

- 路径长度、调度总步数、最大并行液滴数和重规划次数。
- 不同运动/视觉噪声条件下的成功率、丢帧次数、卡滞次数和电极开关次数。
- CSE、ZJU、CSC 等目标图形的仿真调度结果。

这些数据能够证明控制策略在软件模型中的正确性与鲁棒性，不能替代实物闭环实验结果。
