# 实现状态

本文区分软件验证、固件实现和仍需用户实物验证的能力。

## 统一第二章实验界面（2026-10-04）

`main.py` 现有“手动电极 / 自动化路径规划”之外增加“第二章单液滴实验”页，
接入 `dmf.experiment` 的 offline、dry_run、experiment。实验独占资源，支持
后台执行、最新画面预览、状态/动作显示、停止释放及独立日志目录。
第一章硬件测试页及其专属命令客户端已移除。原有仿真和本地性能优化保留。
真实 U-Net 权重、相机 SDK、测量标定及实物结果仍待配置/验证。

## 实物模式界面（2026-10-04）

运行本目录 `main.py`，在运行模式中选择“实物”。运动真实度、视觉噪声、
仿真故障模式、步进调试、复位仿真和故障注入测试自动隐藏；串口、
实际电极操作、运行指标及设置导入导出保留。切回“仿真”后恢复原参数。

切换模式会清除上一来源的画面和检测结果；实物模式不生成仿真相机帧，
复位仿真和故障注入回调也不执行。实物设置文件不写入仿真参数。
原自动化路径页仍用于旧策略仿真。第二章实际实验通过新的实验页启动，
OpenCV 相机或厂商 SDK 插件由实验配置选择，不使用旧相机占位接口。

## 当前软件链路结果

| 场景 | 液滴数 | 调度步数 | 最大单步变化电极 | 最大串口时间 |
| --- | ---: | ---: | ---: | ---: |
| CSE | 31 | 29 | 44 | 43.663 ms |
| ZJU | 30 | 43 | 29 | 28.993 ms |
| CSC | 29 | 61 | 42 | 41.406 ms |

详细结果见 `validation/closed_loop_chain/output/`。电路代理默认采用已有单路选通仿真的低耦合参数；当耦合从 0.5 pF 增至 1.22 pF 时，未选节点偏差由 23.529 V 增至 52.928 V，因此 PCB 寄生仍是必须实测的风险。

## 上位机性能优化结果

以当前 PC 上的软件计时为准：

| 项目 | 优化前 | 优化后 | 说明 |
| --- | ---: | ---: | --- |
| 仿真画面生成与检测 | 71.472 ms | 36.171 ms | 同一 50 次测试场景均值，画面从 720 x 720 调整为 520 x 520 |
| 多液滴规划任务提交 | 阻塞 Tk 主线程 | 0.062 ms | 100 次均值；规划在后台计算，结果由主线程安全应用 |
| CSE 总规划时间 | 1662.1 ms | 1485.6 ms | 3 次均值 |
| ZJU 总规划时间 | 1827.7 ms | 1592.0 ms | 3 次均值 |
| CSC 总规划时间 | 1976.7 ms | 1739.7 ms | 3 次均值 |

日志保留最近 2000 行，手动仿真去除了重复画布刷新。实物模式隐藏仿真参数；手动页不显示障碍工具，实物自动页则显示“屏蔽故障电极”。

以上是界面响应和软件规划的测量结果，不是真实液滴运动时间，也不能代替实物闭环验证。

这些数据可证明软件协议、规划和调度链路自洽，不能替代示波器、逻辑分析仪、相机标定和真实液滴实验。
