# 实现状态

本文区分软件验证、固件实现和仍需用户实物验证的能力。

| 范围 | 状态 | 当前证据与限制 |
| --- | --- | --- |
| 20 x 20 核心阵列及外围电极编号 | 软件已实现 | 上位机使用 ID 1-420，并测试四角废液池、侧边储液池及映射。 |
| A* 与多液滴动态调度 | 软件已实现 | 检查同格、对撞、正交/对角拉拽、停靠液滴和动态并行；尚需真实液滴时序验证。 |
| 移动、循环、混合、分裂 | 仿真已实现 | 包含动作状态、电极保持、分裂重试、稳定视觉确认和指标记录。 |
| 视觉稳定门 | 软件已实现 | 目标格连续 5 帧且至少 0.25 s 才推进；电气 `APPLIED` 不代表液滴到达。 |
| 仿真相机与质心检测 | 软件已实现 | 可生成噪声、丢帧和低对比画面，并映射到电极。 |
| 离线视频液滴跟踪 | 软件已实现 | 支持 ROI、质心/前沿、速度和透视映射；已有速度视频不是真实 20 x 20 阵列。 |
| 统一离线视觉实验框架 | 软件已实现 | Threshold/Background共享结果契约、完整420电极多边形、帧级CSV/JSON和统一评测已实现；Hough/KCF/U-Net/DeepLab及五状态阈值待真实Pilot数据。 |
| PC 到 STM32 原子批量协议 | 软件与固件已实现 | `BEGIN/SET/COMMIT`、同序列重试、`ACK:APPLIED`、1 s 超时、`ALL_OFF`；尚未实机串口联调。 |
| STM32 20 x 21 行列扫描 | 固件已实现 | 300 Hz 固定扫描、blank/load/drive、前后缓冲和帧边界提交；尚未 Keil/逻辑分析仪验证本分支。 |
| STM32 LCD/触摸 | 手动测试专用 | 自动任务期间由 PC 占有；LCD 不显示或执行自动实验流程。 |
| 工业相机实时采集 | 接口待实现 | 已移除 `CAMERA:*` 串口占位；相机应通过 PC USB3/厂商 SDK 采集，最终 SDK 尚未确定。 |
| 真实阵列四角标定 | 算法存在，未接实时主流程 | `ArrayGridCalibration` 可做透视映射，仍需固定相机后的标定界面与参数保存。 |
| 软件链路验证 | 已通过 | 移动、混合、分裂、循环、CSE、ZJU、CSC 的原子协议、扫描构造、串口预算和低耦合电路代理通过。 |
| 实物视觉闭环 | 未验证 | 必须完成相机 SDK、阵列标定、固件烧录、高压板和真实液滴测试。 |
| 硬件安全与可靠性 | 未验证 | 包括耐压、爬电距离、寄生耦合、关断恢复、疏水层一致性和污染实验。 |

## 当前软件链路结果

| 场景 | 液滴数 | 调度步数 | 最大单步变化电极 | 最大串口时间 |
| --- | ---: | ---: | ---: | ---: |
| CSE | 31 | 29 | 44 | 43.663 ms |
| ZJU | 30 | 43 | 29 | 28.993 ms |
| CSC | 29 | 61 | 42 | 41.406 ms |

详细结果见 `validation/closed_loop_chain/output/`。电路代理默认采用已有单路选通仿真的低耦合参数；当耦合从 0.5 pF 增至 1.22 pF 时，未选节点偏差由 23.529 V 增至 52.928 V，因此 PCB 寄生仍是必须实测的风险。

这些数据可证明软件协议、规划和调度链路自洽，不能替代示波器、逻辑分析仪、相机标定和真实液滴实验。
