## 3. 三步统一固定等待规则

对七个数值模型各三步，定义

\[
t_{m,k}^{\mathrm{ref}}=t_{m,k}^{\mathrm{ref,first}}-t_{m,k}^{\mathrm{Applied}},\qquad
T_{\mathrm{fixed}}=\frac{\left\lceil10\max_{m=0,\ldots,6;\ k=1,2,3}t_{m,k}^{\mathrm{ref}}\right\rceil}{10}.
\]

这是同一个三步统一等待值，运行时从相应模拟Applied起计；不得按步骤、场景、模型或测试结果另选等待。最大值包括响应、运动、减速和参考驻留耗时，不能再把Applied前的请求延迟混入同一计时起点。

独立参考沿用半径0.288 mm、速度0.192 mm/s、连续驻留0.15 s；不使用覆盖门或识别输出生成参考。该计算是模型内基线确定，不是实物安全等待时间。

### 标定准入失败条件

1. 七个数值模型任一计划步缺失、未尝试或未在预声明观察窗内建立参考：标定未通过，保留原记录；不删除失败、不补抽、不只对成功步骤取最大值。
2. 计算得到T_fixed **大于10.0 s**：停止准入，不截断为10 s后继续；恰为10.0 s符合本次数值上限，但实施前须测试固定等待与超时同tick的优先级。
3. 第8结构模型的失败同样完整报告，但不从其成功片段反向修改七模型计算规则。
4. 尚未运行，所以T_fixed数值为空；不沿用4.65 s冒充本协议计算结果。

## 4. 三类时间与153 s候选预算

| 时间 | 定义 |
|---|---|
| 控制预算 | 策略允许继续决策与提交合法事务的最长时间；当前候选153 s |
| 后随访时间 | Complete/Stop后继续观测的独立时段；本轮未指定数值，执行前单独预声明 |
| 实际耗时 | 该trial真实记录的Complete或Stop时刻；失败不自动写为153 s |

源码路径假设：源准备最多0.04＋2 s；每步初次、2 Retry、Recovery后Resend构成最多4次10 s运输等待，1次10 s恢复等待及5次0.04 s模拟Applied。

\[
B_{\max}=0.04+2+3(4\times10+10+5\times0.04)=152.64\ \mathrm{s}.
\]

153 s为向上取整候选，必须在实际实现的可达路径、计时网格、pending/终止顺序复核后才能接受。不将配置中的每步Applied硬上限7误当作当前所有可达流程均会使用7次；不将真实串口ACK重发或实物输出路径暗中纳入该模拟公式。

四策略共享初始条件、保护通道、Retry/Recovery预算和驱动延迟。A_fixed不生成视觉ArrivalEvent；共享保护上限不表示四策略必然发生同样的保护动作。
