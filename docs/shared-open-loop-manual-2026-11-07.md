# 定时开环运行期间的手动电极开关

## 操作规则

日常实物上位机仍从 `main.py` 启动，开环任务仍在“手动电极”页设置。
选择“电极开关”后，运行期间也可以点选任务外电极。

1. 原任务所有路线电极不能手动开关，包括已经经过的电极、当前电极、未来电极及已完成组终点。拒绝操作时记录具体原因，不暂停任务，也不提供确认覆盖。
2. 任务外且不冲突的电极可以开、关。新点亮的电极作为额外保持点，不会被下一任务步骤关闭；手动关闭的额外保持点不会被下一步骤恢复。
3. 为避免意外拉拽，任务外开关仍检查剩余任务路线与全部保持电极的同格、正交/对角邻接冲突。故障/邻接提醒区在开环期间不接受手动变更；停止任务后，原来的手动故障测试能力保留。
4. 开环期间点击只改变选中的电极，不使用旧手动操作中“开此电极同时关邻居”的隐含行为。多电极变更中只要有一个任务电极/冲突点，整次拒绝，不部分发送。
5. 手动与任务共用一个事务队列。已有事务先完成，随后优先处理排队的手动操作，再执行到期的任务步。每电极仅允许一个待确认手动意图，重复点击会提示等待，不按旧颜色猜测下一次切换。
6. 绿色/关闭底色来自最近确认的 APPLIED。黄色虚线框表示待确认，不提前改变底色；故障红框保留。颜色表示确认过的命令状态，不是独立测得的实际高压或液滴位置。
7. 手动事务 ACK 不增加任务步号，也不重新开始原任务的停留计时。手动操作可能因串口排队使下一任务步延后，绝不会让其早于设定停留时间。
8. 主动暂停期间仍可操作安全的任务外电极。停止、全部关闭、断开或关窗取消尚未发送的手动操作，先收敛在途事务，再执行原有释放流程。通信失败/外部 SYNC 导致状态未知时，停止后续发送；外部 SYNC 不冒充 APPLIED 改变运行期颜色。

最新用户决定替代此前“冲突先暂停、确认后允许手动”的讨论，当前版本不提供该覆盖行为。

## 可追溯记录

每次新开环会话继续输出 `steps.csv`、`electrode_events.csv` 与 `manifest.json`，另新增 `manual_commands.csv`。
手动记录包含意图编号、明确的电极变更、排队/提交/确认/拒绝/取消/失败、任务阶段及实际事务序列号。
路径表记录实际组合活动集合；原始编译路线和初始保持点不随手动操作更改。
