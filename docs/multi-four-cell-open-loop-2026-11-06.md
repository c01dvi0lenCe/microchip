# 多组四宫格定时开环与研究配置界面调整

> 后续更新：2026-11-07用户确定日常上位机仅真实实验、开环全部放“手动电极”、视觉放“自动化路径规划”。当前操作以`docs/operator-only-ui-2026-11-07.md`为准；下文早期自动页入口说明保留作历史记录。

## 操作入口

运行 `python main.py`。日常界面仅保留“手动电极”“自动化路径规划”，不再显示第二章研究配置/运行页。`run_experiment.py`、研究配置文件、算法及历史实验保留，后续由研究工作流单独准备；没有删除研究成果。显式构造 `research_ui=True` 仅保留为既有研究适配器回归入口，不是日常启用方式。

“自动化路径规划”页新增“路径定时开环”：

1. 普通单滴路径：选择“规划移动路径”，按原画布设置起终点及路径，预检后启动。仅适用于原“移动”任务，不把分裂/混合任务当作普通移动路径执行。
2. 多滴四宫格：选择“多组四宫格”，添加组；逐组选“起点”“四点”“终点”并点击画布。四点必须按实际绕行顺序构成核心2×2，起终点均在四点中。每组是一个已有液滴，不会自动汇合或产生新液滴。
3. 设置共同停留时间0.1–60秒、圈数1–9999。路径从起点走完整圈数，再按相同方向的前缀到终点。示例190→191→211→210→190，再到191→211。
4. “预检”冻结前检查全程同格、对向交换、邻接吸引风险、已完成组与额外保持点、故障/保护区域。冲突时整体拒绝，没有部分组先执行。
5. “开始开环”同步执行；“人工单步”或“单步”也不绕过停留与在途ACK。“暂停/继续”保持电极，继续后保守重新等待当前停留。“停止”保留最后确认电极；在途命令仍须等待ACK或失败收敛。

多组编辑时收起旧仿真辅助控制，保留画布空间；切回规划路径后恢复。画布箭头/组标签表示命令路线，不是相机测得的液滴位置。终点另有组ID“终”标签。

## 执行语义

每个全局步只生成一份完整活动集合，包含每组当前位置、已完成组终点及额外保持电极。已有非任务活动点不静默关闭，作为保持点纳入预检。

复用原BEGIN/SET/COMMIT差量事务客户端、APPLIED及最多两次同sequence通信重试。所有组共用一个事务和确认计时；没有每组独立串口线程。停留从事务确认返回的主机单调时间起算，原始APPLIED软件接收另由事务observer记录；前者是保守计时锚点，二者都不是实际高压沿或曝光时刻。

正常停止/序列完成保留末电极；窗口关闭、断开串口、切换到仿真时仍保留本次实物会话的释放责任并请求ALL_OFF。释放失败报告未知，不能把本地清屏当成断电。断线后无法证明物理释放；软件不能撤销已发送命令，独立硬件隔离/急停仍必要。

相机可独立预览、录像。当前推进只使用电极确认和时间，不读取识别Mask、模拟液滴或ArrivalEvent。“命令序列完成”不等于“实际液滴路径成功”。

- 无法导通实测点：399、400；不扩展邻居。

- 持续导通故障不能靠软件发送0或收到ALL_OFF证明隔离。实物运行前需独立电气核查。

## 研究配置与日志

每次运行在 `results/hardware_open_loop/<独立会话目录>` 保存manifest、steps.csv、electrode_events.csv：冻结路线/设置、保持集合、源码SHA256、主机时间、请求和确认、结束状态。仿真预演明确标记simulation，不伪造真实串口ACK；步日志使用simulated_applied。

日志创建失败不启动；请求日志溢出后不继续提交电极命令；结束封存失败保留错误提示。研究模式offline/dry_run串口禁用语义不变。

## 视觉闭环准入

当前开环可先做软件预演与录像准备。视觉闭环按以下条件逐项接入，而非仅“接上相机”即可：

1. 核对选定模型导出与现有适配器的RGB/NCHW、尺寸、归一化、概率/阈值语义；同日内部验证不能代替独立泛化。
2. 对当前装夹/相机图像验证420电极配准，不静默复用旧照片H。
3. 用真实视频和独立人工到达参考做离线事件核查；Mask分割GT与到达/状态GT分开。
4. 在线dry_run只记录不输出AM，检查时间、旧帧、延迟及事件一次性消费。
5. 经独立电气安全、计量核查及明确实物试验授权后，先做有限单滴短路径，再讨论多组视觉闭环。

本次不运行真实AM输出，不修改STM32、300Hz扫描、事务协议、第三章调度或冻结S1/S2/S3，不训练新模型，不提交或推送。
