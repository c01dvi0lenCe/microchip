# 第二章仿真完成后的Chat审查交付约定

生效日期：2026-10-28。依据用户要求，每次完成一轮仿真，必须同时交付一份可以直接上传给Chat审查的PDF；不能只给动画或口头结论。

## 必备内容

1. 本轮科学问题、范围及与上轮的实际变更。
2. 模型、地图、液滴尺寸、时间域、速度与其他参数；区分模拟假设、真实输入及尚未标定项目。
3. 实际trial身份、版本、seed和数量；输入、源码、Mask/CSV、图稿与manifest来源hash。
4. 实际运行结果与分母，失败、缺失、未尝试、不确定情况保留；没有统计时明确n=1。
5. 原始日志对应图稿、关键帧和事件时间线；图内无说明性小字，条件与解释放图注。
6. 软件机制、几何/时序正确性、视觉/物理真实性和算法性能四类验收分别报告。
7. 单元/回归/独立审计的实际命令与结果；未执行项如实写明。
8. 用户指出的异常、未关闭问题、结论边界、下一步最小修订与待审问题。

## 交付规则

- 报告独立另存，附可编辑Markdown及机器可读来源索引；不覆盖先前报告/仿真。
- 不将软件测试通过写成模型与实物一致，不将n=1写成算法性能验证。
- 形变外观等质性问题尚未关闭时，报告状态必须明确“形态待修订/待验收”。
- 只有文字整理或既有结果打包时，写明新增仿真trial=0。
- 不默认发送到其他Chat；由用户上传审查，除非另外明确授权。

本约定不授权新增实验、扫描、算法改动、硬件输出、Commit或Push。
