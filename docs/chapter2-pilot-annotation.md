它不打开相机或AM串口，不改上位机闭环策略，也不会创建训练权重。

## 1. 电极地图

在“电极地图”页按逻辑ID1、ID20、ID400、ID381顺序点四个外边界角，
不是电极中心，也不是整个玻璃板或储液池外角。间距用确认后的3.2 mm。
缩放和滚动可查看细节；高倍率只绘制当前视口，避免整张20 MP照片四倍放大占用大量内存。

检查叠加网格在中心、边缘均对齐，再勾选核对项并保存。
六段原视频分别保留地图，避免摄像头/芯片移动后盲目共用同一标定。
地图覆盖1–420，核心仍为20×20，外围20个不是第21列。外围模板不能冒充实测多边形，
涉及外围电极的正式标签须先在地图中补实际`pixel_overrides`。

每次保存地图产生新版本；同一原视频相关短片自动获得减去ROI偏移的地图。
地图改动后，旧状态标签停止计入已审核表，需要重新核对，旧Mask保留。
如网格对齐仍有系统偏差，应排查镜头畸变或补实测多边形，不能仅凭四角对齐声称标定完成。

## 2. Mask

“Mask与状态”页显示液滴草稿覆盖层，用笔刷补液滴、擦除背景，核对后勾选Mask并保存。
草稿使用既有阈值基线，不是U-Net结果或GT；边界、反光和干扰仍需人工复核。
原图不修改，Mask保存为同尺寸0/255 PNG。不确定状态时可先只审核Mask。
重新编辑Mask会取消当前帧审核勾选，不能将修改后的草稿沿用旧的已审核状态。

## 3. 源、目标与状态

先看对应短片/原录像，再通过地图点选或填写实际源、原定目标ID。
观察到液滴最终停在哪，并不能代替“原定目标”；不知道原操作意图时保留空白。
状态结合前后帧、源/目标关系人工判断，无法确认时用Unknown并写备注。
拉伸不自动等于Partial，不动不是Deviation，检测丢失也不是Deviation。
状态审核必须有已确认地图、已审核Mask及明确源/目标，不从算法预测反向生成GT。

63张关键帧只是一批起始样本，不是足够的训练集或五状态测试集。
可用“补充短片帧号”加入中间帧，再逐帧审核；新增帧保留原视频帧号和ROI偏移。
训练/验证/测试按独立采集批次分开；本批只有一天，split全部unassigned，不随机拆邻近短片。

## 数据文件

- `annotations.csv`：全部工作帧，未核对的状态为Unknown，草稿Mask不写进GT路径。
- `segmentation_reviewed.csv`：只有已审核Mask，可作为分割样本清单；可能还没有状态/电极标签。
- `state_reviewed.csv`：地图、Mask、源/目标及状态均核对的帧。
- `maps/`、`maps_roi/`：全图版本地图和对应短片坐标地图。
- `review_status.json`：审核数量、未有审核GT的类别，以及真实时间/命令记录的缺口。
- `draft_masks_overview.png`：草稿总览，不是准确率证明。

只以清单中的审核标记选数据，不能把`masks_draft`或版本历史中的所有PNG直接当成GT。
其他目录版本文件保留用于追溯，原数据包不覆盖。

## 真实时间、闭环日志和Deviation

10月13日旧视频没有逐帧接收时间与电极日志，不能补造过去的开关或将容器fps当成真实运动时钟。
本工具保留`container_fps_unverified`标记。旧数据先用于轮廓标注和定性状态检查，
真实速度、运输延迟和时间阈值需要新版上位机新录视频及配套日志。

新采集：先开始录像，再手动操作电极，停止后检查录像旁`recording.json`为complete。
手动电极ACK日志只能建立驱动与画面的关系，不是视觉事件驱动的闭环成功证据。
模型和参数准备好后先dry_run核对，最终experiment的视觉状态/动作/命令日志才用于闭环验证。

Deviation不要求现在强行制造。自然偏离要保留原定目标和完整时序；真实样本不足就明确标记。
既有合成Recovery场景可以检验软件分支，但须与真实样本分开，不计入真实偏离或恢复成功率。
