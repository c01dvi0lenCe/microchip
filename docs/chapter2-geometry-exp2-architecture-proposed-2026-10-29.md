# 实验二：真实几何多电极闭环的架构与公平基线草案

2026-10-29。设计准备，未实现新控制器、未生成新试验，不替代已冻结历史S3。

## 1. 研究问题

在相同外生扰动、真实设计几何、液滴轮廓和控制预算下，判定时刻改变下一电极激励后，是否产生路径完成性、无支持请求或执行时间的差别？允许M2/M3相同、固定等待胜出或所有方法均成功；不以复杂方法必须胜出作为验收。

## 3. 最小因果链与接口

共同P0源准备完成 → 判定器读实际Mask/时间/任务 → 一次消费或固定计时到期 → request → pending → 模拟Applied切换active → 响应延迟/有效交叠 → World后续运动 → 新Mask。

- World只接收激励，不接收“算法已到达”答案；保持液滴实际位置，不能在逻辑step改变时瞬移到目标中心。
- 任务上下文、激励段、软件attempt分开。同目标Retry不凭软件epoch清除物理驻留；Recovery真实改变激励才分段。
- pending期间不新发不合法事务；request、Applied、运动响应、曝光/可用/处理时间各自记录。这里均是simulation，不冒充真实ACK或高压输出。
- 轮廓仍复用已通过库并按方向旋转；转弯/提前切换的形态适用性是模型假设，不称独立视频验证。
- 在提前切换的任意位置下，需要明确运动目标改变的连续性。建议在独立World适配层保留位置/速度并限制速度，不直接沿用“每任务从电极中心出发”的单步轨迹。运动重定向及形态进度定义先通过手算机制，再锁定参数；当前不编造其已实现。

## 4. 四组与公平保护

A_fixed、M1、M2、M3均共享P0、C0、观测、基础停止条件、Retry/Recovery预算。A只在共同P0使用视觉，运输计时不生成虚假ArrivalEvent。三种到达门与实验一B定义一致；不将M3纯到达门冒称完整五状态控制器。

完整五状态保护如另需检验，应以同到达门×两保护通道桥接，不能把保护输入的差异归于S/K。当前不增加第五主算法或新有利工况。

外生随机数组预先生成并由时间/位置索引，算法轨迹分叉后可以产生不同Mask；不能在不同策略中按调用次数取不同外生样本。公平性是同外生场，不是强制不同闭环共享同一观察轨迹。

## 5. 固定时间与预算的冻结原则

不直接复用旧模型1.2 s等待。可选两方案：

1. 推荐：从共同名义模型推导固定等待，并在独立开发条件一次验收后冻结。例如响应0.18 + 最小跃度T=1.875×3.2/1.4 + 0.15 s驻留≈4.616 s，向上取相机周期为Applied后4.65 s。**这只是候选计算，不是已冻结或实测等待值**。
2. 在预声明开发数据选择固定等待，使名义正常条件具有指定覆盖率；不得观察正式结果后选值。

共同总预算应覆盖预声明最慢三步名义时间及合理保护余量；旧24 s不能自动继承。源准备失败、运输中止、预算耗尽、工作流完成但无独立支持、独立支持路径完成互斥；每trial固定3计划步，Retry/Recovery不产生新计划步。

## 6. 指标和归因

独立支持路径完成率、工作流完成率分开。分别评价request与Applied的参考支持，另记录切换后真实模拟运输是否失败；参考前不直接等同危险。

完整分母保留源准备失败、未尝试、Unknown观测、失败及删失。成功完成时间只在成功子集解释；全计划预算化代价与其惩罚规则独立预声明。额外Applied按Retry/Recovery/resend分类，不把请求数冒充Applied。

## 7. 下一次架构准入

在实验一B具体协议获准后可同步实现独立实验二机制，不等待M3优于M2。先验证任意位置切换、无交叠不迁移、pending/Applied时序、同目标Retry参考连续性、转弯邻接和外生数组索引。未完成这些机制及预算冻结前不运行正式多seed闭环比较。

本轮没有实验二性能结论，没有新增实物、高压、AM、U-Net或第三章改动。
