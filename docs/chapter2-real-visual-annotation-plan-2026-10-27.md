本轮核对最新清单、原视频SHA256、审核图/Mask哈希及裁剪来源。逐帧ROI像素复核只检查数据一致性，不重新运行分割或计算正式精度。完整记录见新审查包`sources/10段真实视频与绑定状态.csv`和`18张审核Mask_ROI与坐标来源核查.csv`。

## 2. 坐标、时间及任务清单先行

每条候选任务必须登记video_sha256、采集group/chip/loading/mounting别名、source_frame范围、帧号基准、时间源、ROI、图像域、source/target确定依据、route/step和可见性。source/target不能从待测算法输出反推；看不清电极或任务不明时标task_unverified，不进入正式电极任务到达评价，但仍可用于纯图像分割Pilot。

只有经过该视频图像域绑定的地图才能显示电极辅助；旧照片H、默认map_version或相同分辨率不是绑定证据。无可信时间时先保留帧号区间，不把frame/fps改名为曝光秒。现有10段视频也不因状态未知而全部弃用，应按可见性、任务身份、时间和地图分别分级。

## 3. 独立双评审到达事件标注协议

### 3.1 操作定义的预审

标注对象是单滴迁移任务的**可见到达**，不是World内部位置/速度真值或液滴三维体积完全进入。人工定义独立于G/Q/W/S/K阈值：明确目标电极、可见主体进入/停留、细颈与残留的处理、遮挡/透明边界及可解释稳定性。不得复制eta≥0.85或“5帧0.25 s”作为人工真值生成公式。

建议先用6–10个短片段做标注规范Pilot，覆盖明确到达、短暂跨越后返回、拉伸/源残留、遮挡和未到达；该数量是工作量建议，不是样本效力承诺。先由两评审形成书面操作定义，再冻结正式测试片段及规则。暂不能一致判定的现象进入uncertain，而不是强行统一标签。

### 3.2 标注界面与盲法

复用已有视频/图像缩放画布、帧浏览和人工审核记录方式，不重复开发分割工具。本轮只交付流程与空表，尚无专用双评审到达界面完成记录。

每位评审独立查看原始连续视频、原帧号和经核验的任务/电极位置。隐藏算法预测Mask、eta曲线、五状态、确认事件、算法名称与另一评审坐标。若叠加电极轮廓依赖尚未验证H，则不显示为精确真值，先解决绑定或明确降级到无电极任务的视觉描述。

既往已看过算法图稿的记忆可能影响盲法，应登记reviewer_exposure，不声称完全双盲。评审A和B分别封存CSV及哈希，B不读取A的标注；第三人/共同复核的裁决另存，不覆盖原始记录。不能由Codex代填已审核标志。

### 3.3 原始标注内容

- 每计划步记录观察窗、最后明确未到达帧、首次明确到达帧，以及各自时间来源。
- 到达参考为区间[L,U]，不从两帧间线性插值造单点；若片段开始时已经到达，记录左删失/起点到达信息，不能假定是t=0发生。
- 单独记录进入后离开、目标支持episode、source_ready及Recovery激励切换（若没有控制记录，标未知）。事件首次到达和当前驻留支持不是同一信息。
- 状态取arrived/not_arrived/uncertain/occluded/right_censored；not_arrived仅在完整可解释观察窗内成立。左删失由扩展字段保留，不强塞进现有枚举。
- 记录边界原因：细颈/残留、多滴邻近、反光、模糊、手部遮挡、目标区不可见、任务ID不明、时钟不可用。

同目标Retry如果物理驻留连续不清空人工参考；离开目标或真正切换激励后分段，避免旧到达无限支持后续请求。无电气记录的旧视频不能假装能够验证真实Recovery应用时刻。

### 3.4 两评审一致性与裁决

按planned step给出两评审状态一致数、参考区间重叠数、区间端点差/事件时间差、需裁决数和不可判别数；样本小且层级相关时以描述为主，不强行计算精密CI或泛化准确率。重复点击和同视频多帧不是独立采集。

裁决必须可追溯原帧、两份记录及理由；不能因某算法被评为提前而挪动人工区间。高分歧时优先修订操作规范并另立版本，已冻结正式标注不静默改写。

## 4. 时间不确定性与评分接口

SDK设备ticks、SDK主机时间、接收monotonic/perf、视频PTS和实际曝光不是同一概念。人工区间需包含帧间采样、曝光宽度、掉帧、人工边界和时钟映射残差；滚动快门语义未知时记录未知，不能自动假定全局曝光。

若已知人工总参考区间[L,U]及事件总时间区间[c_low,c_high]，确定提前需c_high<L；确定支持需事件区间晚于U并完全处于当前有效支持episode；相交为时间不确定。延迟区间为[c_low-U,c_high-L]。不确定性已含在端点时不重复叠加；没有时钟映射就保留各域记录，不相减。

已有`dmf/vision/event_evaluation.py`支持human、reviewed、provenance、全计划step清单、到达区间和不确定/遮挡/右删失，预测时间仍为单点。其非零参考区间内部含上界为模糊，t>U为确认，零宽区间允许零延迟。双时间区间、左删失、当前episode及独立激励段是后续适配要求，不能把空模板写成已实现评分。

planned trial/step为总账；参考到达分母、可判别事件分母、漏预测、Unknown、未尝试、删失分别报告。不能把人工不确定全部当算法错误，也不能将其删去后只报“可判别准确率”。无正式参考时不运行正式评价。

## 5. 新增独立采集与困难样本建议

| 维度 | 应新增材料 | 目的/分组 |
|---|---|---|
| 独立加液 | 不同日期、重新加液/清洁后的完整单滴序列 | 独立loading/session组，而非同轮视频切段 |
| 装夹与成像 | 最终高度固定后的参考图和视频；重新装夹另登记 | 最终配准与漂移；每个图像域绑定H |
| 芯片 | 如要讨论跨芯片泛化，增加另一实际芯片并标识 | 单芯片多轮不能证明跨芯片泛化 |
| 任务路径 | 核心不同位置、方向，清晰source/target和完整起止 | 电极任务约束验证；外围需独立安全批准 |
| 形态 | 启动、跨电极、拉伸/细颈、源区残留、部分到达、返回 | 事件边界及Mask规范，不以算法状态自动分类 |
| 成像困难 | 黑滴低对比、反光/局部过曝、边缘模糊、运动模糊、失焦、邻近对象 | 真实困难材料需实际存在，不把透明背景低对比代称黑滴低对比 |
| 时序困难 | 实际帧间隔抖动/丢帧和处理可用时刻，原始sidecar保留 | 真实缺帧与人工删除帧压力测试分开标注 |
| 负对照 | 无目标、非目标液体/气泡、静态电极、可辨未到达 | 检测失败与伪Mask边界，不能预设错误来自模型 |

建议先补约3个独立加液/采集组用于工作流验证，至少预留一个后采组不参与调参；这是Pilot建议，不保证正式统计效力。正式train/val/test是否足够，应在完成规范Pilot并确认批次差异后另审。若独立组不足，保持全体为开发数据；同源帧不跨集合。

下一批Mask可先选60–90张分层代表帧，优先困难条件与事件边界；精确数量由实际可见性和标注负担确定。到达事件评价需要连续片段与任务上下文，不能仅靠这些静态Mask。新增采集仅为计划，本轮不采集、不启动高压。
