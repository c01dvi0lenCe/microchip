# 实验二：单活动电极闭环机制开发交付记录

## 范围与身份

本轮只完成批准的独立接口、确定性机制测试、四个正常开发案例及两个World-only切换反例。未执行随机仿真、正式seed、实物输出或高压实验。新代码位于`dmf/chapter2_geometry_sim/exp2/`，旧实验一及历史S1/S2/S3未覆盖或合池。

地图使用FBC6-3真实420电极Gerber设计轮廓，路径190→191→192→172，设计节距3.2 mm。沿用430个有效形态的进度重放；面积等效直径4.0 mm，垫片0.8 mm只作为记录。所有动力学及时间参数均为SIMULATION开发假设。

## 新接口

| 模块 | 职责 |
|---|---|
| `spec.py` | 开发参数、严格积分/控制时钟网格校验与身份 |
| `world.py` | 单活动目标原子替换、待生效事务、正交叠门、连续位置/速度响应 |
| `controller.py` | 共同P0、A_fixed/M1/M2/M3到达策略、一次性消费及共同有界保护 |
| `reference.py` | 内部位置/速度/驻留独立参考，按实际激励切换分段 |
| `runner.py` | 保存实际相机Mask、捕获任务身份、可用时间、请求及Applied |
| `persistence.py` | CSV/JSON/PNG、输入和源码摘要 |

四方法不是新的完整五状态算法：M1为C0+G，M2为C0+G+Q+W，M3再加S/K，A_fixed按本步Applied+4.65 s推进且不伪造ArrivalEvent。共同P0和有限Retry/局部Recovery是保护通道。本轮没有新增完整五状态或Deviation保护。

## 模型变更与不可混用事项

旧单步最小跃度轨迹不能在中途替换目标后自然形成闭环，本轮新增有界速度松弛World：期望速度为位置误差/0.75 s、上限1.4 mm/s；速度松弛0.25 s，加速度上限4 mm/s²，dt=0.01 s。Applied延迟0.04 s、响应延迟0.18 s。位置/速度不因真实换目标而重置；同目标Retry不重置物理驻留。只有实际轮廓与激励目标正交叠才允许运动，这是模型门而非经验证的电润湿物理定律。

形态相位响应和转角速率也为新增开发假设，没有由视频进行动力学标定。不能沿用旧实验一4.65/4.72 s判定结果，也不能把新旧模型混作一个统计批次。

## 实际开发结果

每方法n=1，共四trial；每trial三计划步、4001个World时间点、800张实际生成的Mask，固定随访至40 s。四方法均在0.35 s完成共同源准备，191模拟Applied为0.39 s。全部正常案例无Retry/Recovery、无交叠阻断。

| A_fixed | 5.04 / 9.73 / 14.42 | 是 | 是 | 0 | 0 | 是 |
| M1 | 3.55 / 6.75 / 10.00 | 是 | 是 | 3 | 2 | 否 |

第三步为Complete事件，没有下一电极请求或Applied；不计作新增电极事务。当前开发评分文件的`unsupported_requests`沿用通用决策标记，包含最终Complete，应按表中“推进/完成决策”解读，而非串口/电极事务次数。单独只计真实Update请求时，M1/M2/M3均为2次未获当时参考支持，A_fixed为0。正式统计接口冻结前应澄清该字段命名；本轮不改已保存数据。

M2/M3前两步参考分别在3.81、7.26 s建立，晚于请求0.01 s、早于Applied。不能用Applied时获支持追认更早请求；也不能把参考前请求直接解释为物理危险或运输失败。M1最终目标参考在Complete之后的固定随访内建立，旧任务没有被未来参考追认。

本次正常开发案例仍不能证明M3相对M2有增量收益，也不能由n=1为四策略排序。

## 机制修复与独立复核

1. 预算边界：必须为请求后Applied留足预算；精确截止Applied允许，Stop之后不允许事务改变终端状态。
2. 参考端点：已观测的闭合未到达与截至H仍在建立的参考分别处理，不把所有无参考标记成删失。
3. 时钟：非积分网格控制/响应参数直接拒绝；曝光结束和处理可用时间可非网格并在之后的合法tick交付。
4. 审计：从持久化PNG/多边形/World/事件独立复算G/Q/S/K、C0、P0及W窗口、事件时刻与一次性消费、物理参考和三步支持关系，不调用控制器或原评分器。已包含更改核心指标并重新hash后仍能检出的回归。

实际3200张Mask独立审计通过。局部159项、全量1070项（1跳过）及软件闭环链验证通过；渲染后的三项绘图辅助测试也通过。旧源码、DEV和历史资产保护及实验一B正式批次摘要以交付包`QA/软件回归/verification.json`为最终凭据。
