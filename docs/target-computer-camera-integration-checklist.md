# 目标电脑相机接入与实时视觉验收清单

## 目的与边界

本清单供目标电脑安装相机 SDK 后完成现场相机接入。上位机的检测功能只采集、分割和记录图像；本阶段不把视觉结果接入 M3、不自动推进电极、不发送 AM 控制命令，也不要求改写 STM32 固件。手动和定时开环任务仍由操作者负责。

摄像头通过 PC USB3/厂商 SDK 直接连接，不经 STM32 串口。相机接入、SDK 故障或检测停止不得改变开环任务状态。

## 目标电脑需完成的工作

### 1. 本机环境与 SDK

- [ ] 检出 `codex/whole-chip-realtime-vision` 分支，按 `docs/whole-chip-realtime-vision.md` 建立独立视觉环境并安装已匹配的依赖。
- [ ] 在目标电脑安装与工业相机型号、驱动版本匹配的厂商 MVS 软件及 Python 绑定；不把厂商 SDK 或 DLL 提交到仓库。
- [ ] 复制 `configs/camera_mvs.local.example.yaml` 为本地配置，填写本机 SDK 绑定目录及相机序列号；本地配置不提交、不上传。
- [ ] 将独立 G4 推理模型包复制至 `models/g4_unet` 或通过界面选择外部目录；用部署文档中的 SHA256 核对权重。模型包不是 Git 交付物。
- [ ] 首次启动只做依赖/模型/SDK 预检，不自动连接相机、串口或高压输出。

### 2. 实际取流核验

操作者手动连接并开启相机后，先在“原图”模式检查：

- [ ] 确认实际相机型号、序列号、像素格式、分辨率、曝光、增益、帧率/触发模式，并记录镜头、焦距/对焦和相机至芯片高度。不能从录像编码帧率反推传感器曝光或采集帧率。
- [ ] 确认 `FramePacket` 中设备帧号/设备计数与主机接收时间来源；设备时间与主机单调时钟分开保存。未证实为曝光时间的时间戳不得标为曝光时刻。
- [ ] 连续采集并同时预览、录像至少10分钟；报告相机交付帧率、实际图像尺寸、帧号缺口、队列覆盖、断流/重连、CPU/GPU/显存占用。
- [ ] 检查检测启停不阻塞预览或录像；检测显示的 Mask/叠加必须与其来源帧号一致；关闭检测不停止相机、录像或开环任务。
- [ ] 分开报告相机接收FPS、任务区域完整检测FPS、周期巡检进度、处理时延、结果年龄和主动跳过帧。不得把接收FPS当作模型检测FPS。

### 3. 配准矩阵的建立、绑定与复用

配准的复用单位是**稳定的一套相机—镜头—芯片装夹条件**，不是单帧、单个液滴任务或每段录像。

一套条件通过验收后，可在该次装夹会话内复用同一矩阵；换录像文件本身不要求重新配准。启动新会话时应检查矩阵对应的条件和图像域，并用可见电极网格/独立检查位置验证残差。

以下任一变化发生时，旧矩阵必须失效并重新配准或重新验收：

- 相机或芯片重新装夹、平移、旋转，或芯片高度/倾斜变化；
- 镜头、焦距、变焦或对焦明显变化；
- 图像分辨率、方向、裁剪、缩放或像素坐标定义变化；
- 启动检查发现电极网格相对图像发生不可接受的位移/形变。

目标电脑现场操作：

1. 在目标电脑和最终实验装夹条件下采集一张完整芯片参考图，记录相机、镜头、分辨率、芯片高度、盖板和装夹条件。
2. 从 FBC6-3 的420电极设计地图建立图像到设计平面的候选变换；拟合点与独立检查点分开保存。不得把11月6日录像的自动候选 H 当作最终标定。
3. 在独立检查点上报告像素误差及地图坐标误差；通过项目预先规定的验收限值后，生成带来源图像哈希、设计地图哈希、矩阵、坐标域、装夹条件、检查误差和创建时间的 calibration manifest。
4. 每次新会话核对 manifest 的设备/图像域与当前设置，并执行网格对齐检查。通过则本会话复用 H；不通过则只允许像素级观察/记录，禁止电极ID空间特征和闭环输入。
5. 运行期间可低频监视可见网格/固定参考点残差；超限即将配准标为失效并退出电极空间判定，不静默沿用旧矩阵，也不需要每帧重算 H。

### 4. 检测与开环并行检查

- [ ] 操作者执行手动或定时开环时，检测只读相机图像并保存日志，不取得串口/事务对象，不改变电极状态。
- [ ] 用新采集视频核对整芯片扫描候选和用户选定的像素观察区；尚未通过配准时，像素区域不得标成电极区域、毫米坐标、持续液滴身份或到达事件。
- [ ] 多个区域/任务时核对任务ROI优先级、区域版本切换后旧结果清空、区域轮转和巡检让行；检测不能将旧区域Mask显示在新任务/新帧上。
- [ ] 记录多个液滴和困难画面，但无独立人工GT时只报告候选/运行表现，不计算分割准确率。

## 验收交付

目标电脑验收后保存：

- 本机环境、相机、镜头及 SDK 版本记录；
- 相机本地配置（仅本机保存）及不含敏感序列号的脱敏摘要；
- 10分钟运行的原始日志、统计表和错误/丢帧说明；
- 本次装夹的参考图与 calibration manifest（实际相机图像按实验数据管理，不提交 Git）；
- 配准拟合点/独立检查点、RMSE/P95/最大误差及验收判定；
- 模型权重 SHA256、检测配置及软件版本；
- 开环并行、检测启停、录像和结果源帧一致性检查记录。

本清单完成仅代表目标电脑相机感知和当前装夹配准验收。它不代表真实到达识别、STM32/AM 高压闭环或液滴运输性能已验收。
